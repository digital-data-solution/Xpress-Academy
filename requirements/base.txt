# Real bug this closes: certificate PDFs (and any future course cover
# uploads) were saved to local disk, which Render's free tier neither
# serves in prod (DEBUG=False disables Django's media-serving view,
# by design — never re-enable that in production) nor persists across
# redeploys anyway (no disk). S3Boto3Storage against Supabase's
# S3-compatible Storage API (see config/settings/prod.py) fixes both:
# a real public URL, and files that survive a redeploy. Only active
# in prod when AWS_STORAGE_BUCKET_NAME is set — falls back to local
# storage (same as dev) otherwise, so this doesn't require the bucket
# to exist yet to deploy the code itself.
#
# Resend is called directly via requests (already installed) in
# apps/engagement/gateway.py, matching apps/payments/gateway.py's
# pattern — no separate Resend SDK needed.
